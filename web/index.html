Jouer en plein écran, sans la barre de recherche

  1. Touche le bouton Partager (le carré avec la flèche vers le haut).
  2. Choisis « Sur l'écran d'accueil » (laisse « Ouvrir comme app web » activé si tu le vois).
  3. Ouvre le menu du navigateur (⋮), puis choisis « Ajouter à l'écran d'accueil » ou « Installer l'application ».
  4. Lance ensuite le jeu avec son icône : il s'ouvre en plein écran, comme une application.

Attention : le jeu lancé depuis l'icône a sa propre sauvegarde ; la partie jouée ici, dans le navigateur, ne le suit pas.
